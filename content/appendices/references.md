# References

*Reviewed: October 21, 2026.*

Grouped by theme, with publication dates for fixed works and review dates for living documentation. Source descriptions identify the claim supported and the kind of evidence. Historical tool releases document the book's dated examples. Entries disclose access limitations.

## Foundations: engineering practice, decision records, plain-text-as-code

- Sam Newman: ["Backends For Frontends"](https://samnewman.io/patterns/architectural/bff/). *November 18, 2015*. Original description of the client-specific backend pattern.
- Andrej Karpathy: ["Vibe coding"](https://x.com/karpathy/status/1886192184808149383). X, *February 2, 2025*. Original post introducing the term.
- Simon Willison: ["Not all AI-assisted programming is vibe coding (but vibe coding rocks)"](https://simonwillison.net/2025/Mar/19/vibe-coding/). *March 19, 2025*. Practitioner commentary distinguishing vibe coding from AI-assisted programming with code review and understanding.
- Ian Sommerville: ["Software Engineering", 10th edition](https://www.pearson.com/en-us/subject-catalog/p/software-engineering/P200000003258?view=educator). Pearson, *2015* (copyright 2016). Textbook treatment of software processes and lifecycle activities.
- David Farley: ["Modern Software Engineering: Doing What Works to Build Better Software Faster"](https://www.informit.com/store/modern-software-engineering-doing-what-works-to-build-9780137314744). Addison-Wesley, *2021*. Engineering principles and feedback. With Jez Humble: ["Continuous Delivery: Reliable Software Releases through Build, Test, and Deployment Automation"](https://www.informit.com/store/continuous-delivery-reliable-software-releases-through-9780321770424), Addison-Wesley, *2010*. Deployment pipelines and delivery feedback. The associated [continuousdelivery.com](https://continuousdelivery.com/) site defines continuous delivery (reviewed October 21, 2026).
- Kent Beck: ["Test-Driven Development: By Example"](https://ptgmedia.pearsoncmg.com/images/9780321146533/samplepages/0321146530.pdf). Addison-Wesley, *2002* (copyright 2003). Original book on the test-first cycle and red-green-refactor practice.
- Dan North: ["Introducing BDD"](https://dannorth.net/blog/introducing-bdd/). First published in *Better Software*, *March 2006*, republished online September 20, 2006. Original account of behavior-driven development and executable acceptance criteria.
- Paul Hammant: [trunkbaseddevelopment.com](https://trunkbaseddevelopment.com/) (reviewed October 21, 2026) and ["Trunk-Based Development and Branch By Abstraction"](https://leanpub.com/trunk-based-development), Leanpub (available by *2020*). Author-maintained explanations of shared-trunk development, short-lived branches, and branch by abstraction.
- Yue Jia and Mark Harman: ["An Analysis and Survey of the Development of Mutation Testing"](https://doi.org/10.1109/TSE.2010.62). *IEEE Transactions on Software Engineering*, vol. 37 no. 5, *2011*, pp. 649-678. Research survey covering mutation testing and equivalent mutants. An [earlier technical report](https://mutationtesting.uni.lu/TR-09-06.pdf) provides an accessible version of the work.
- ISTQB: ["Certified Tester Foundation Level Syllabus v4.0.1"](https://istqb.org/wp-content/uploads/2024/11/ISTQB_CTFL_Syllabus_v4.0.1.pdf). *September 15, 2024*. Versioned primary documentation for equivalence partitioning and boundary value analysis.
- Michael Nygard: ["Documenting Architecture Decisions"](https://www.cognitect.com/blog/2011/11/15/documenting-architecture-decisions). *November 15, 2011*. Original ADR writeup covering context, decisions, consequences, and supersession.
- Karl Popper: ["The Logic of Scientific Discovery"](https://www.routledge.com/The-Logic-of-Scientific-Discovery/Popper/p/book/9780415278447). First English edition, Hutchinson, *1959*. Falsifiability as a criterion of demarcation. Applying the idea to testable agent instructions is book synthesis. The linked publisher page describes a later Routledge edition.
- Oliver Kopp, Anita Armbruster, and Olaf Zimmermann: [MADR template](https://adr.github.io/madr/) (reviewed October 21, 2026) and ["Markdown Architectural Decision Records: Format and Tool Support"](https://ceur-ws.org/Vol-2072/paper9.pdf), CEUR-WS Vol. 2072, *2018*. Original paper and maintained documentation for the Markdown ADR format.
- ISO/IEC/IEEE: ["42010:2022: Software, systems and enterprise - Architecture description"](https://www.iso.org/standard/74393.html). *November 2022*. Published architecture-description standard, distinguishing architecture from an architecture description. Publisher metadata and abstract checked October 21, 2026.
- Flemming N. Larsen: ["Plain Text as Code Manifest"](https://github.com/Plain-Text-as-Code) (reviewed October 21, 2026). Author's statement of the philosophy applied in the Foundation chapters.
- Eric Holscher and the Write the Docs community: ["Docs as code"](https://www.writethedocs.org/guide/docs-as-code/) (reviewed October 21, 2026). Community documentation on applying development tools and workflows to documentation.
- Mermaid: [open-source documentation](https://mermaid.ai/open-source/intro/index.html) and [live editor](https://mermaid.live) (reviewed October 21, 2026). Primary documentation and tooling for diagrams defined in text.
- Simon Brown: [C4 model](https://c4model.com/) (reviewed October 21, 2026). Creator-maintained documentation for architecture abstractions and diagrams.
- Simon Brown: [Structurizr documentation](https://docs.structurizr.com/) (reviewed October 21, 2026). Primary documentation for model-based architecture diagrams and the Structurizr DSL.
- D2 contributors: [D2 documentation](https://d2lang.com/) (reviewed October 21, 2026). Primary documentation for the diagram language and its layout and export options. The Mermaid comparison in this book is an editorial choice.
- Frederick P. Brooks Jr.: ["The Mythical Man-Month: Essays on Software Engineering"](https://www.pearson.com/en-ca/subject-catalog/p/mythical-man-month-the-essays-on-software-engineering-anniversary-edition/P200000000149/9780132119160). The analogy to `skeleton.md` is book synthesis.
- Apache Maven Project: ["Introduction to the Standard Directory Layout"](https://maven.apache.org/guides/introduction/introduction-to-the-standard-directory-layout.html) (reviewed October 21, 2026).
