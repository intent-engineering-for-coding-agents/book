# About the Author

Flemming Nørnberg Larsen is a principal software developer based near Aalborg, Denmark. As of October 2026, he works at Elsevier, building and maintaining software systems alongside coding agents.

He wrote the [Plain Text as Code Manifest](https://github.com/Plain-Text-as-Code) before writing this book. The Foundation topic in this book is its application to agentic engineering.

The book grew out of the articles in the [Architecture as Code example repository](https://github.com/flemming-n-larsen/architecture-as-code-example) and a frustration with advice focused on prompts or specs alone. The approach developed here also needs documented decisions, agent instructions, and evidence that the implementation matches the intended change.
