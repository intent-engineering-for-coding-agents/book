# Privacy

This site loads GoatCounter to measure traffic to the book's pages. It does not use advertising trackers or set analytics cookies.

When a browser contacts GoatCounter, the service receives the page path, referrer, browser information, and IP address. GoatCounter's [privacy policy](https://www.goatcounter.com/help/privacy) says it keeps the IP address and full browser header in memory for session counting for up to eight hours, without storing either in its database. It stores traffic counts and derived data such as browser type and approximate location. When enabled, GoatCounter's optional individual-pageview setting also stores a record for each view. Its current value is not recorded in this repository.

GoatCounter processes the analytics data. GitHub Pages also processes requests needed to serve this site under the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

*Sources: GoatCounter, "Privacy policy" (reviewed October 24, 2026), collected fields, in-memory session data, stored aggregates, and optional individual pageviews. GitHub, "General Privacy Statement" (effective April 27, 2026), processing for GitHub services. The site's analytics script is configured in `.vitepress/config.mts`.*

The site has no accounts, contact forms, advertising, or personalized tracking. Feedback and contributions go through GitHub, where GitHub's own privacy terms apply.
